## ⚠️ Важные напоминания

- **Медиа-файлы**: На Free плане они удаляются при перезапуске. Используйте S3 для продакшена.
- **База данных**: На Free плане БД останавливается после 90 дней неактивности. Для продакшена используйте платный план.
- **Логи**: Всегда проверяйте логи в Render Dashboard при проблемах.

## 🔧 Полезные команды для Shell в Render

```bash
# Проверка конфигурации
python manage.py check --deploy

# Создание суперпользователя
python manage.py createsuperuser

# Применение миграций (если нужно)
python manage.py migrate

# Сборка статики (если нужно)
python manage.py collectstatic --noinput
```
