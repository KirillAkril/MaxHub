## 🗄️ ШАГ 2: Создание базы данных PostgreSQL

**Это нужно сделать ПЕРВЫМ делом, так как база данных создается дольше всего.**

### Шаг 2.1: Открыть форму создания БД
1. На странице Dashboard (главная панель Render)
2. В левом верхнем углу найдите большую синюю кнопку **"New +"**
3. Наведите на нее мышку - откроется меню
4. В меню выберите **"PostgreSQL"**

### Шаг 2.2: Заполнить форму
На открывшейся странице вы увидите форму. Заполните так:

1. **Name** (Название):
   - В поле введите: `maxhub-db`
   - Это просто название для вас, может быть любым

2. **Database** (Название базы данных):
   - Оставьте значение по умолчанию или введите: `maxhub`

3. **User** (Пользователь):
   - Оставьте значение по умолчанию или введите: `maxhub_user`

4. **Region** (Регион):
   - Выберите ближайший к вам (например: **Oregon (US West)** или **Frankfurt (EU Central)**)
   - ⚠️ **ЗАПОМНИТЕ ЭТОТ РЕГИОН!** Веб-сервис должен быть в том же регионе

5. **PostgreSQL Version** (Версия):
   - Оставьте по умолчанию (обычно последняя доступная)

6. **Plan** (Тариф):
   - Выберите **"Free"** (бесплатный)
   - ⚠️ На бесплатном тарифе БД останавливается через 90 дней неактивности

7. В самом низу страницы нажмите синюю кнопку **"Create Database"**

### Шаг 2.3: Дождаться создания БД
1. Появится страница с информацией о создании
2. Дождитесь, пока статус изменится с "Creating..." на "Available"
3. Это займет 1-3 минуты
4. ⚠️ **НЕ закрывайте эту страницу!** Вам понадобятся данные из нее

## 🌐 ШАГ 3: Создание веб-сервиса (ваше приложение)

### Шаг 3.1: Открыть форму создания веб-сервиса
1. На странице Dashboard нажмите **"New +"** (левая верхняя кнопка)
2. В меню выберите **"Web Service"**

### Шаг 3.2: Подключить репозиторий GitHub
1. На странице "Create a New Web Service" вы увидите список ваших репозиториев
2. Найдите репозиторий **"maxhub"** (или как вы назвали)
3. Нажмите на него
4. Если репозитория нет в списке:
   - Нажмите **"Configure account"** или **"Connect account"**
   - Разрешите доступ к GitHub
   - Вернитесь и выберите репозиторий

### Шаг 3.3: Заполнить основные настройки
После выбора репозитория откроется форма. Заполните так:

1. **Name** (Название сервиса):
   - В поле введите: `maxhub`
   - Или любое другое название (например, `maxhub-app`)

2. **Region** (Регион):
   - ⚠️ **ВАЖНО!** Выберите ТОТ ЖЕ регион, что и для базы данных!
   - Если БД в Oregon, то и веб-сервис в Oregon

3. **Branch** (Ветка):
   - Оставьте `main` (или `master`, если это ваша основная ветка)
   - Если не знаете, оставьте как есть

4. **Root Directory** (Корневая папка):
   - **ОСТАВЬТЕ ПУСТЫМ** (если проект в корне репозитория)

5. **Runtime** (Среда выполнения):
   - Должно автоматически определиться как **"Python 3"**
   - Если нет, выберите вручную

6. **Build Command** (Команда сборки):
   - Найдите это поле
   - Сотрите все, что там есть (если есть)
   - Скопируйте и вставьте эту команду:
     ```
     pip install --upgrade pip && pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate
     ```
   - (Добавлено `pip install --upgrade pip` для избежания проблем с установкой пакетов)

7. **Start Command** (Команда запуска):
   - Найдите это поле
   - Введите:
     ```
     gunicorn maxhub.wsgi:application
     ```

### Шаг 3.4: Настроить переменные окружения (Environment Variables)

**Это самый важный шаг!** Прокрутите страницу вниз до раздела **"Environment Variables"** (или **"Advanced"**).

Нажмите на кнопку **"Add Environment Variable"** несколько раз и добавьте следующие переменные:

#### Переменная 1: DJANGO_SECRET_KEY
1. Нажмите **"Add Environment Variable"**
2. В поле **"Key"** введите: `DJANGO_SECRET_KEY`
3. В поле **"Value"** нужно ввести секретный ключ. Сделайте так:
   - Откройте PowerShell (или терминал) на вашем компьютере
   - Выполните команду:
     ```bash
     python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
     ```
   - Скопируйте длинную строку, которая появится (она будет примерно такой: `django-insecure-abc123xyz...`)
   - Вставьте эту строку в поле **"Value"** в Render

#### Переменная 2: DJANGO_DEBUG
1. Нажмите **"Add Environment Variable"** еще раз
2. **Key:** `DJANGO_DEBUG`
3. **Value:** `false`

#### Переменная 3: DJANGO_ALLOWED_HOSTS
1. Нажмите **"Add Environment Variable"** еще раз
2. **Key:** `DJANGO_ALLOWED_HOSTS`
3. **Value:** Введите URL вашего сайта на Render (будет показан после создания сервиса)
   - Пример: `maxhub.onrender.com`
   - **ВАЖНО:** После создания сервиса Render покажет вам URL (что-то вроде `https://maxhub-xxxx.onrender.com`)
   - Скопируйте только доменную часть (без `https://`), например: `maxhub-xxxx.onrender.com`
   - Если не знаете URL, можете использовать: `*.onrender.com` (разрешит все поддомены Render)

#### Переменные для базы данных (4-8)

Теперь нужно скопировать данные из базы данных. Вернитесь на страницу вашей БД (она должна быть открыта в другой вкладке).

**На странице базы данных:**
1. Прокрутите вниз до раздела **"Connections"**
2. Найдите **"Internal Database URL"**
3. Вы увидите что-то вроде:
   ```
   postgresql://maxhub_user:abc123xyz@dpg-xxxxx-a.frankfurt-postgres.render.com:5432/maxhub_abc1
   ```
4. Этот URL нужно разобрать на части

**Как разобрать URL:**
Формат: `postgresql://USER:PASSWORD@HOST:PORT/DATABASE`

Пример разбора:
- Если URL: `postgresql://maxhub_user:abc123xyz@dpg-xxxxx-a.frankfurt-postgres.render.com:5432/maxhub_abc1`
- То:
  - USER = `maxhub_user` (часть до первого `:`)
  - PASSWORD = `abc123xyz` (часть между `:` и `@`)
  - HOST = `dpg-xxxxx-a.frankfurt-postgres.render.com` (часть между `@` и `:5432`)
  - PORT = `5432` (цифра после последнего `:`)
  - DATABASE = `maxhub_abc1` (часть после последнего `/`)

**Добавьте переменные в Render:**

4. **DB_NAME**
   - **Key:** `DB_NAME`
   - **Value:** Скопируйте часть DATABASE из URL (после последнего `/`)

5. **DB_USER**
   - **Key:** `DB_USER`
   - **Value:** Скопируйте часть USER из URL (до первого `:`)

6. **DB_PASSWORD**
   - **Key:** `DB_PASSWORD`
   - **Value:** Скопируйте часть PASSWORD из URL (между `:` и `@`)

7. **DB_HOST**
   - **Key:** `DB_HOST`
   - **Value:** Скопируйте часть HOST из URL (между `@` и `:5432`)
   - ⚠️ **ВАЖНО:** Хост должен быть ПОЛНЫМ, например: `dpg-xxxxx-a.oregon-postgres.render.com`
   - ❌ **НЕПРАВИЛЬНО:** `dpg-xxxxx-a` (без домена)
   - ✅ **ПРАВИЛЬНО:** `dpg-xxxxx-a.oregon-postgres.render.com` (с полным доменом)

8. **DB_PORT**
   - **Key:** `DB_PORT`
   - **Value:** `5432`

## 👤 ШАГ 5: Создать суперпользователя (администратора)

После успешного деплоя нужно создать администратора сайта:

1. На странице вашего веб-сервиса в Render найдите меню вверху
2. Выберите вкладку **"Shell"** (или **"SSH"**)
3. Откроется командная строка в браузере
4. Введите команду и нажмите Enter:
   ```bash
   python manage.py createsuperuser
   ```
5. Вас попросят ввести:
   - **Username:** придумайте имя (например: `admin`)
   - **Email address:** введите ваш email (например: `admin@example.com`)
   - **Password:** придумайте надежный пароль (минимум 8 символов)
   - **Password (again):** введите тот же пароль еще раз
6. После ввода всех данных появится сообщение "Superuser created successfully"

## ⚠️ Важные замечания

### Медиа-файлы (изображения, загруженные пользователями)
- На бесплатном плане файлы **УДАЛЯЮТСЯ** при перезапуске сервиса
- Для продакшена лучше использовать AWS S3 или Cloudinary
- Для тестирования это нормально

### База данных
- На бесплатном плане БД **останавливается** через 90 дней неактивности
- Для продакшена лучше использовать платный план

### Проблемы?

1. **Ошибка "Bad Request (400)":**
   - **Причина:** Проблема с настройкой ALLOWED_HOSTS
   - **Решение:**
     1. В Render откройте ваш веб-сервис
     2. Перейдите в "Environment" (Переменные окружения)
     3. Найдите переменную `DJANGO_ALLOWED_HOSTS`
     4. В поле "Value" укажите ваш URL на Render:
        - Найдите URL вашего сайта вверху страницы сервиса (например: `https://maxhub-xxxx.onrender.com`)
        - Скопируйте только доменную часть (без `https://`), например: `maxhub-xxxx.onrender.com`
        - Вставьте это значение в `DJANGO_ALLOWED_HOSTS`
     5. Нажмите "Save Changes"
     6. Сервис автоматически перезапустится
   
   - **Альтернативное решение:** Если не хотите указывать конкретный домен:
     - В поле `DJANGO_ALLOWED_HOSTS` введите: `*.onrender.com`
     - Это разрешит все поддомены Render (работает для любого сервиса на Render)

2. **Ошибка "Error loading psycopg2 or psycopg module":**
   - **Решение 1:** Обновите файл `requirements.txt` в вашем репозитории:
     1. Откройте `requirements.txt` в редакторе
     2. Найдите строку `psycopg2-binary==2.9.9`
     3. Измените на `psycopg2-binary==2.9.10`
     4. Сохраните, закоммитьте и отправьте в GitHub:
        ```bash
        git add requirements.txt
        git commit -m "Update psycopg2-binary version"
        git push origin main
        ```
     5. Render автоматически пересоберет проект
   
   - **Решение 2:** Если первое не помогло, попробуйте обновить Build Command:
     1. В Render откройте ваш веб-сервис
     2. Перейдите в "Settings" → "Build & Deploy"
     3. В поле "Build Command" измените на:
        ```
        pip install --upgrade pip && pip install -r requirements.txt && python manage.py collectstatic --noinput && python manage.py migrate
        ```
     4. Нажмите "Save Changes" и "Manual Deploy"

2. **Сайт не открывается:**
   - Проверьте логи (вкладка "Logs" на странице сервиса)
   - Убедитесь, что все переменные окружения установлены

3. **Ошибка базы данных:**
   - Проверьте, что все переменные DB_* правильно скопированы
   - Убедитесь, что используете "Internal Database URL" (не External)
   - Проверьте, что БД и веб-сервис в одном регионе

4. **Статические файлы не загружаются:**
   - Подождите еще 1-2 минуты (они собираются при деплое)
   - Проверьте логи на наличие ошибок collectstatic
